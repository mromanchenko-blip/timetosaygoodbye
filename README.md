# Час прощатись — сайт-запрошення

Статичний сайт (HTML + CSS + JS, без фреймворків).

## Деплой на Vercel

**Варіант 1 — через GitHub (рекомендую):**
1. Створи новий репозиторій на GitHub і залий туди вміст цієї папки.
2. На vercel.com → **Add New → Project** → вибери репозиторій → **Deploy**.
   Нічого налаштовувати не треба: все вже прописано у `vercel.json`.

**Варіант 2 — з терміналу:**
```bash
npm i -g vercel
cd chas-proshchatys
vercel          # перший раз — відповісти на питання (все за замовчуванням)
vercel --prod   # продакшн-деплой
```

## Що де змінити

| Що | Де |
|---|---|
| Тексти, дата, місце | `index.html` |
| Подія в календарі (час кінця, адреса, опис) | `script.js` (об'єкт `EVENT`) **і** `event.ics` |
| Кольори, розміри, швидкість анімацій | `styles.css` |
| Картинка для шерингу | `og.png` (1200×630) |

Подія зараз: 11.12.2026, 18:30–21:00 (Київ).

## Корисне

- `?final` в кінці адреси — одразу показує фінальний екран без інтро (зручно для перевірки).
- Якщо підключиш власний домен, у Vercel → Settings → Environment Variables додай
  `SITE_URL=https://твій-домен` і передеплой — тоді шерінг-картинка підтягнеться з нього.
- Шрифт: Helvetica Neue (як у макеті) на Mac/iPhone; на Windows та Android — дуже схожий Arimo з Google Fonts.
- Локальний перегляд: `npx serve .` і відкрити http://localhost:3000
